# Project Scope - Atlas: Travel Risk & Cost Intelligence Dashboard

## In-Scope Features
- Select a destination country to display Safety Index, Cost of Living Index, and Local Purchasing Power.
- Merge static safety data (`safety_data.csv`) with dynamically fetched Kaggle cost-of-living data.
- Render interactive comparison charts using Plotly (Safety vs Cost for top countries).
- Generate targeted travel risk summaries using the Groq Cloud API.

## Out-of-Scope Features
- User authentication, login, or saving user profiles.
- Live real-time currency conversion or weather tracking.
- Storing user travel queries in a persistent database.
